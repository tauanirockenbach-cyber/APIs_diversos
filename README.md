# 📡 API Pokémon (e Disney) - APIs Diversos

Este diretório contém scripts em Python desenvolvidos para realizar o consumo de APIs públicas, realizando requisições, tratando os dados recebidos e demonstrando conceitos fundamentais de integração e manipulação de JSON.

## 🚀 Arquivos no Repositório

* **`pokemon.py`**: Script responsável por consumir a [PokeAPI](https://pokeapi.co), buscando informações detalhadas sobre os monstrinhos (como nome, tipos, habilidades ou estatísticas).
* **`disney.py`**: Script focado no consumo da [Disney API](https://disneyapi.dev), focado em buscar personagens e dados relacionados ao universo Disney.

## 🛠️ Pré-requisitos

Antes de executar os scripts, certifique-se de ter o Python instalado em sua máquina e a biblioteca `requests` (comumente utilizada para requisições HTTP).

Se necessário, instale a dependência utilizando o comando abaixo:

```bash
pip install requests
```

## ⚙️ Como Executar

Abra o terminal na pasta deste projeto e execute o script desejado utilizando o Python:

**Para rodar o script do Pokémon:**
```bash
python pokemon.py
```

**Para rodar o script da Disney:**
```bash
python disney.py
```

## 🧠 Tecnologias Utilizadas

* **Python 3**
* **Biblioteca `requests`** (para comunicação HTTP)
* **JSON** (para estruturação e leitura de dados)
